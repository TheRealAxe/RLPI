# RLPI · Plateau — dossier de passation

Dossier à donner à Claude Code pour refondre l'interface RLPI dans la direction G · Plateau.

**Utilisation.** Copie ce dossier dans le dépôt de l'application (par exemple `docs/plateau/`), lance Claude Code à la racine du dépôt et demande-lui de lire `docs/plateau/CLAUDE.md` avant de commencer.

| Chemin | Contenu |
|---|---|
| `CLAUDE.md` | Le brief pour Claude Code : ordre de lecture, règles, méthode, définition de « fini ». |
| `design/tokens.css` | Variables CSS : couleurs, polices, espacements, coupes. |
| `design/tokens.json` | Les mêmes valeurs, avec l'usage et les contrastes de chaque couleur. |
| `design/plateau.css` | Classes de base de la grammaire visuelle. |
| `design/DESIGN.md` | La direction visuelle et ses règles. |
| `spec/ARCHITECTURE.md` | Navigation en quatre onglets et répartition des sections actuelles. |
| `spec/COMPONENTS.md` | Spécifications des composants. |
| `spec/COPY.md` | Ton, formats, phrases de lecture. |
| `spec/DATA.md` | Contrat de données. |
| `data/sample-axe.json` | Exemple complet relevé sur le profil d'Axe. |
| `reference/` | Écrans de référence en HTML ; ouvrir `index.html`. |
